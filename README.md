# Personal Portfolio Website

A modern, responsive portfolio website built to showcase my **education, technical skills, projects, and internship experience**.  
Designed with a clean UI, smooth animations, and full responsiveness across devices.

---
---

## 📌 About

This portfolio website serves as a professional online presence, highlighting my academic background, technical expertise, and hands-on project experience.  
It is built using **Tailwind CSS** and **JavaScript**, focusing on simplicity, performance, and user experience.

The website also includes a fully functional **contact form integrated with EmailJS**, allowing visitors to send messages directly to my email without requiring a backend server.

---

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Smooth animations and transitions
- Sections for education, skills, projects, and experience
- Functional contact form with EmailJS integration
- Clean and minimal UI using Tailwind CSS
- Fast loading and optimized layout

---

## 🛠️ Tech Stack

- **Frontend:** HTML, JavaScript
- **Styling:** Tailwind CSS
- **Email Service:** EmailJS
- **Version Control:** Git & GitHub
